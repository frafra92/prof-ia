Mentions légales & Politique de confidentialité

Dernière mise à jour : mai 2026

François Gaillard

Contact : disponible via le formulaire de l'application

2. Hébergement

Le service est hébergé sur Railway (Railway Corp, San Francisco, USA).
Les données sont stockées sur des serveurs situés aux États-Unis.
Pour plus d'informations : railway.app/legal

3. Modèle d'intelligence artificielle

Prof IA utilise l'API Claude d'Anthropic (San Francisco, USA) pour générer les réponses pédagogiques.
Les conversations sont transmises à Anthropic pour générer les réponses. Anthropic applique sa propre politique de confidentialité disponible sur anthropic.com/privacy.

4. Données collectées

Prof IA collecte et stocke les données suivantes :

  • Code famille — identifiant choisi par l'utilisateur, stocké en clair sur le serveur
  • Profil élève — prénom, âge indicatif, centres d'intérêt, niveau scolaire
  • Historique des conversations — les 40 derniers échanges par élève
  • Progression — points XP, badges, streak quotidien, sujets explorés

Aucune donnée personnelle sensible (email, nom de famille, adresse, données bancaires) n'est collectée.

5. Utilisation des données

Les données collectées sont utilisées exclusivement pour :

  • Personnaliser les réponses pédagogiques du tuteur IA
  • Conserver la progression de l'élève entre les sessions
  • Générer des statistiques d'usage anonymes

Les données ne sont jamais vendues ni transmises à des tiers à des fins commerciales.

6. Protection des mineurs

Prof IA est conçu pour être utilisé par des enfants sous la supervision d'un adulte responsable.

  • Le code famille est géré par un adulte (parent ou tuteur)
  • Les conversations sont filtrées pour éviter les contenus inappropriés
  • Aucun compte email n'est requis pour les élèves

Conformément au RGPD, le traitement des données des mineurs de moins de 15 ans nécessite le consentement parental. En créant un code famille, l'adulte consent au traitement des données décrit dans cette politique.

7. Vos droits (RGPD)

Vous disposez des droits suivants sur vos données :

  • Droit d'accès — vous pouvez consulter vos données via l'interface
  • Droit de suppression — vous pouvez supprimer un profil élève et toutes ses données depuis l'application
  • Droit de portabilité — contactez-nous pour obtenir une copie de vos données

8. Durée de conservation

Les données sont conservées tant que le code famille est actif. En l'absence d'activité pendant 12 mois, les données peuvent être supprimées automatiquement.

9. Cookies

Prof IA utilise uniquement le localStorage du navigateur pour mémoriser votre code famille. Aucun cookie tiers ni traceur publicitaire n'est utilisé.

10. Contact

Pour toute question relative à vos données ou pour exercer vos droits, contactez-nous via l'application ou à l'adresse indiquée en section 1.
